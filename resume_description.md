**Intelligent Perfect Pose & Health Analysis** (IEEE ICHI 2025, in press)
*   Architected and developed a full-stack mobile application for real-time human pose estimation and correction, achieving publication in the prestigious IEEE International Conference on Health Informatics.
*   Engineered the frontend using Flutter, integrating Firebase for user authentication and Firestore for data storage, resulting in a seamless and responsive user experience.
*   Constructed a Python backend with a Flask API to process video streams, utilizing MediaPipe for precise body landmark detection.
*   Designed and trained a novel CNN-LSTM model with TensorFlow and Keras to analyze pose sequences, providing users with actionable feedback to improve form and prevent injury.
*   Led the development team using Agile methodologies, conducting weekly scrum meetings and managing the codebase through Git version control and strategic merging.
