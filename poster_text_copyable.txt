PROBLEM & SOLUTION SECTION
=================================================================================

Problem & Solution

🎯 The Guidance Gap:
Fitness apps show videos but can't analyze your form.

📱 Ineffective Feedback:
Generic tips like "good job" are not actionable.

⚠️ High Risk:
Improper form leads to poor results and risk of injury.

🎯 Our Solution:
Deliver lab-level biomechanical analysis using just a smartphone.

=================================================================================
METHODOLOGY SECTION
=================================================================================

Methodology

1️⃣ MediaPipe extracts 33 body landmarks (x,y,z coordinates)

2️⃣ Geometric analysis calculates cosine similarity vs. reference poses

3️⃣ Joint angle extraction for 8 key body joints

4️⃣ CNN-LSTM processes temporal sequences for classification

5️⃣ Dual scoring provides comprehensive feedback

SYSTEM ARCHITECTURE SECTION
=================================================================================

System Architecture

Flutter Mobile App (iOS/Android)
↓
Camera Capture & Image Upload
↓
MediaPipe Pose Detection Engine (33 Body Landmarks)
↓
Flask API Server (Python Backend)
↓
Dual Analysis Engine:
├── Geometric Analysis (Cosine Similarity)
└── CNN-LSTM Model (223K parameters)
↓
Specific Feedback & Corrections Output

=================================================================================
KEY FEATURES & TECHNOLOGY SECTION
=================================================================================

Key Features & Technology

🚀 Core Technology:
• MediaPipe: 33-point landmark detection with 95%+ accuracy
• Dual Analysis Engine:
  - Geometric similarity using cosine distance
  - CNN-LSTM enhancement
• Real-time Processing: <2 second analysis response
• Cross-platform Flutter framework

⚡ Performance Specs:
• Input: 30-frame sequences
• Features: 51-dimensional feature vectors
• Architecture: Conv1D + LSTM + Dense layers
• Precision: ±0.1° joint angle measurements
• Feedback: Specific corrections (e.g., "increase knee angle by 15°")

🔧 Technical Innovation:
• Dual scoring system design
• Specific feedback generation
• Progress tracking integration
• Extensible pose database
